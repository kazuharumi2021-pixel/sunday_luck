# SUNDAY LUCK

GitHub Pages用PWAです。フォルダ内の全ファイルをリポジトリ直下へアップロードし、Settings → Pages → Deploy from a branch → main / root を選択してください。

## 主な機能
- 毎週の作戦を抽選（バランス統計・開運・ランダム・MIX）
- ロト7、ロト6、ナンバーズ4、ナンバーズ3
- ナンバーズのセット固定／申込タイプ抽選
- 週単位で確定し、次の日曜まで固定
- 結果・当せん金・メモ・方式別成績を端末内保存
- ミニロト、ビンゴ5、BIG系、toto系、WINNER、バスケくじを＋1候補として準備
- iPhoneホーム画面用アイコン、PWA対応

※ 娯楽用です。当せん確率の向上を保証しません。購入機能や外部サイト連携はありません。
