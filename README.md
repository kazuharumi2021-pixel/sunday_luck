# SUNDAY LUCK v2

当せん結果自動取得の第1実装です。GitHub Actionsが平日夜にみずほ銀行の公開結果ページを確認し、`data/results.json`を更新します。アプリは起動時にJSONを読み、確定済み購入番号と照合します。

## 更新方法
既存リポジトリのファイルを、このZIP内のファイルとフォルダで置き換えてください。`.github`、`scripts`、`data`フォルダも必要です。GitHubのActionsタブでワークフローを一度手動実行してください。

## 注意
公式APIではなく公開ページの構造を解析するため、公式サイト側の変更で停止する可能性があります。取得失敗時は既存の最終成功データを保持します。最終確認は公式発表で行ってください。
